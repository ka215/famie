# 運用管理

本番環境の運用手順と実施記録を保存する。環境変数の実値、認証情報、トークン、秘密鍵は保存しない。

- [リリース自動化仕様](release-automation-spec.md)：v0.7.0以降の成果物、CI、代表スクリプト、切り戻しの設計上の正本。
- [運用手順書](runbooks/README.md)：通常リリース、環境固有手順、初期構築、PWA検証の入口。

| ディレクトリ | 記録対象 |
| --- | --- |
| `runbooks/` | デプロイ、障害対応、定常作業の手順 |
| `change-log/` | 本番変更、リリース、構成変更の実施履歴 |
| `backup/` | バックアップ方針、実施記録、復元検証記録 |
