# 家族向けデイリーアクティビティ記録サービス 要件定義書

## 1. システム概要

家族の日々の活動（家事、勉強、健康管理など）を記録・共有するためのWebアプリケーション（PWA）。スマホのホーム画面にインストールして手軽に利用できる構成とする。初期運用は外部からの不審なアクセスを防ぐため、特定のIPアドレス（自宅のグローバルIP）からのみアクセスを許可するクローズド運用とする。

---

## 2. システム構成・技術スタック

| 区分 | 採用技術・環境 | 備考 |
| --- | --- | --- |
| **フロントエンド** | Nuxt 4 (PWA対応) | `@vite-pwa/nuxt` 等を使用 |
| **バックエンド** | PHP 8.4~ / Laravel | APIサーバーとして動作 |
| **データベース** | PostgreSQL 14.13~ | リレーショナルデータベース |
| **サーバー・ドメイン** | CoreServer VPS / `*.ka2.org` | 独自ドメインのサブドメイン運用 |
| **アクセス制限** | IP制限（Laravel Middleware / Web Server） | 自宅の固定/特定IPのみ許可 |

---

## 3. 機能要件

### 3.1 認証・アクセス制御・アカウント管理

* **IPアクセス制限**:
* 指定されたIPアドレス以外からのアクセスに対しては、403 Forbidden（または接続拒否）を返す。


* **ログイン認証**:
* ログインID（任意のアカウント名 または メールアドレス）とパスワードで認証。
* メールアドレスを持たない子供アカウントにも対応。


* **アカウント管理（管理者のみ）**:
* 親（管理者）アカウントのみ、新規ユーザー追加・編集・削除・パスワードリセットが可能。
* 一般の登録画面（サインアップ画面）は外部に公開しない。


* **権限（ロール）管理**:
* **親アカウント（管理者）**:
* 全ユーザーのログの参照・編集・削除が可能。
* ユーザー管理操作が可能。


* **子供アカウント（一般）**:
* 全ユーザーのログの参照が可能。
* **自分のログのみ**編集・削除が可能。





### 3.2 ログ記録・閲覧機能

* **ログ登録・編集**:
* 必須項目: 日付、時間帯（または時刻）、カテゴリ、活動内容（テキスト）。
* 任意項目: 補足メモ。


* **ログ閲覧（タイムライン・一覧）**:
* 家族全員のログを時系列で閲覧可能。
* **期間指定フィルタ**: 開始日〜終了日の指定、またはプリセット（「今週」「今月」など）による表示切替。
* ユーザーごとの絞り込み表示機能。



### 3.3 PWA機能

* **ホーム画面追加**:
* Manifestファイルおよびアイコンの設定により、スマホ（iOS / Android）のホーム画面にアプリとして追加可能。


* **スタンドアロン表示**:
* アプリ起動時にブラウザのアドレスバーを表示せず、ネイティブアプリ風の UI で起動。


* **動作前提**:
* オンライン環境必須（オフラインキャッシュからの投稿・下書き保存は初期フェーズ対象外）。

## 4. データベース論理設計（初期案）

```
[users] (ユーザー)
  - id (PK)
  - username (UQ, ログインID)
  - email (Nullable, 任意)
  - password (Hashed)
  - display_name (表示名)
  - role (enum: 'parent', 'child')
  - timestamps

[categories] (アクティビティカテゴリ)
  - id (PK)
  - name (カテゴリ名: 例: 勉強, 家事, 運動, 外出)
  - color_code (画面表示用のカラーコード)
  - timestamps

[activity_logs] (アクティビティログ)
  - id (PK)
  - user_id (FK -> users.id)
  - category_id (FK -> categories.id)
  - activity_date (日付)
  - activity_time (時間/時間帯)
  - content (内容: text)
  - note (補足メモ: text, Nullable)
  - timestamps

```
