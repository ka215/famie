1. [x] Bug: スマホ（iPhone）だと「アクティビティを記録」モーダル内の「実施日」フィールドの右端と「時刻」フィールドの左端が重なって表示されてしまう。
2. [] Enh: タイムラインの月表示はカレンダー方式にしたい。アクティビティが登録されている日付には登録数の数字を表示するバッヂを付ける。
3. [] Enh: 全ロールのアカウントにて表示名が変更できるようにする。
4. [x] Imp: ログイン画面や設定画面のパスワード入力フィールドに入力値のマスク/生表示を切り替えられるトグルボタン（eyeアイコン等）を付けたい。フィールドの右端に設置する。
5. [] Enh: 保護者アカウントの設定画面から子アカウントの編集・削除ができるようにする。基本的に削除は論理削除。アクティビティの登録履歴がない子アカウントは物理削除でも良い。
6. [] Enh: リワード機能。アクティビティ登録数＝スコアとして月間スコア累計に応じてファミリー内のアカウントにリワードを付与する機能。リワードはトロフィーとして各アカウントが獲得でき、リワード履歴はいつでも閲覧できる。リワードスコアに紐づくトロフィーとリワード内容（説明文）は保護者アカウントが設定できる。設定可能なリワード数は最大n個。
7. [] Enh: 複数家族対応。現在すべてのアカウントは同一集合体への所属になっているが、家族やテナント単位にアカウントが所属できるようにする。家族・テナントへ追加できるアカウント数はn人。
8. [] Enh: 画像アップロード機能。全ロールのアカウントが対象。家族・テナント単位での機能ON/OFFが必要。
9. [] Enh: 親アカウント新規登録機能。ログイン画面からアカウント登録画面へ遷移できるようにし、新規登録したアカウントは新規の家族・テナントに所属する。
10. [] Enh: メールアドレスが登録されているアカウントに対してのログイン招待メールの送信機能。
11. [] Imp: カテゴリの並び替え・編集・削除。親アカウントのみの機能。
12. [] Imp: リリース用スクリプト（バッチかシェル）の作成。公開環境へのリリース手順が煩雑でオペミスでのリリース失敗が怖いので、バックエンド・フロントエンドのリリース作業はできる限り自動化したい。
13. [x] Enh: フロントエンドに Playwright を導入してE2Eテストが実施できるようにする。
