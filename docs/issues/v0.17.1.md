## 2. 現行調査と設計上の前提

- 活動登録は`showModal()`で開くネイティブdialogを使用し、`@cancel.prevent`から無条件で`close`をemitしている。画像入力は隠したfile inputをボタンから開き、changeで変換・プレビューへ進む。
- 画像差し替えは`pages/logs/[id].vue`の通常ページ上のfile inputで行う。ユーザー報告ではこちらは正常。両者の構造差は調査の起点になるが、iPhoneの実際のイベント列は未採取で、cancelが原因と確定したものではない。
- 一覧のメモは`activity.noteText`で「メモ:／Notes:＋本文」を一括表示している。本文は利用者データとして原文を維持している。
- 強度計は`meter`、値0〜3、low=2／high=3／optimum=3。空欄0、不適合1、適合2、24文字以上の適合3という既存判定。画像使用量バーのトラックは高さ0.5rem・rounded-full・ライトbg-slate-200／ダークbg-slate-700。
- READMEは英語。現在は旧タイムライン1枚、日本語画面の説明、将来の複数所属、v0.16.0の移管経緯、開発文書へのリンクがある。公開済み日英機能を紹介する内容へ整理する。

## 3. R01 — iPhone画像選択キャンセル時の登録モーダル維持

### 3.1 期待する動作

画像アップロードを許可された家族で、活動登録モーダルにカテゴリ・日付・時刻・内容・メモを入力し、「画像を選択」を押す。iPhoneの写真ライブラリ／写真を撮る／ファイルを選択等の選択メニュー、またはその先の選択画面から、画像を決定せず戻った場合は次を満たす。

1. 活動登録モーダルを開いたままにし、入力値・表示済み検証文・既存の選択画像を保持する。モーダルの閉じる通知、作成API、画面遷移を発生させない。
2. 画像を新しく選択した場合だけ既存の変換・検証・プレビューへ進む。同じ画像を再度選択でき、繰り返し開閉しても選択不能や変換中表示の残留を起こさない。
3. 既に画像を選んだ後の再選択をキャンセルした場合は、前の選択画像を維持する。画像を取り消す明示操作は従来どおり動作する。
4. 復帰後も入力・画像再選択・保存・明示的な閉じるが可能。背景スクロール抑止とフォーカス制御を維持する。復帰時に不要なキーボード表示や背景へのフォーカス移動を起こさない。

### 3.2 通常の終了操作との区別

画像選択に由来するキャンセル／復帰と、活動登録自体を閉じる操作を区別する。通常時の閉じるボタン、デスクトップのEscape、メンテナンスへの遷移、コンポーネント破棄時の終了は維持する。画像選択後にキャンセル保護が残り、Escapeや閉じる操作が恒久的に無効になる修正は不可。

アクティビティ編集の画像差し替え、画像未許可時、通常の登録・二重送信防止・保存失敗時の入力保持は変更しない。オーバーレイ外側タップによる新しい終了動作、破棄確認ダイアログ、ブラーは追加しない。

### 3.3 実装方針と原因の確定

承認後、関連するdialogのcancel／close、file inputのchange／cancel、focus等の発生順と、親コンポーネント側の閉じる処理を確認する。診断に写真内容・ファイル名・本文等の個人情報を記録しない。調査用の常時ログや端末識別機能を製品へ残さない。

確認できた経路に限定して画像選択ライフサイクルを扱い、選択完了・キャンセル・明示終了・破棄で状態を解放する。イベントが取得できない経路の復帰も検討する。固定時間の無条件保護だけで操作を判定しない。イベント順やブラウザ別の修正方法は原因確認後に選び、既存dialogの全面置換や依存追加は行わない。仕様変更が必要なら連携する。

### 3.4 検証

- 自動：画像選択に伴うキャンセル時のdialog・入力・既存プレビュー保持、作成API未送信、通常Escape／閉じるの復旧、再選択・保存、既存の編集・HEIC変換・メンテナンス回帰を既存E2Eへ追加／再利用する。
- 実機：iPhone Safariで選択メニュー外側タップ、各選択先からのキャンセル、繰り返し開閉、選択・変換・保存、前の画像保持を確認する。可能な撮影経路と利用できない経路を記録し、カメラ／写真への新しいアクセス許可を要求する機能は追加しない。
- iPhone PWAでも実利用経路を確認する。Windows上のPlaywright WebKitだけではOSの画像選択メニューまで再現済みと扱わない。iPhone実機確認をステージングの必須受入とする。

## 4. R02 — 一覧メモの接頭辞をSVGへ置換

- 対象はタイムラインの活動カード内、メモが存在する場合の表示。メモ本文、カードの背景・余白・原文・改行／折返し・リンク動作は維持する。
- `.tools/ka2_svg-icon-list.md`の`aria-label="note-text-outline"`と同じpath／viewBoxを使用する。既存アイコンと同様に`frontend/app/assets/icons/`へSVGを置き、currentColorでライト／ダークの文字色へ追従させる。新しいアイコンライブラリは導入しない。
- 「メモ:」「Notes:」の可視接頭辞だけを外し、アイコン＋メモ本文の横並びとする。アイコンは1rem程度、縮小させず、複数行の本文の先頭に合わせる。本文は残り幅で折り返し、320px幅や長文でも横へはみ出さない。
- アイコン自体は装飾としてaria-hiddenにし、翻訳済みの視覚非表示ラベル「メモ／Notes」を添えて意味を保持する。本文を二重読み上げしない。新しいボタン・ツールチップは追加しない。
- 既存の`activity.noteText`が他で使われていないか確認してから、置換／不要キー整理を行う。日英辞書の同一キーと参照整合を維持する。
- メモなしのカードはアイコン・余白とも表示しない。入力欄・詳細画面・APIの項目名は変更しない。

## 5. R03 — パスワード強度計のスタイル統一

画像使用量バーのトラックに準拠し、全幅・高さ0.5rem・両端丸角・内容のはみ出し防止、ライトのslate-200／ダークのslate-700背景へ揃える。外枠は使用量バーと同じく、目立つ独立した境界線を付けない。

強度計を容量バーの青色へ統一しない。アクティブバーは現在の強度に応じた色の意味と段階を維持し、空欄／不適合／適合／強い状態を確認する。現行ネイティブmeterの配色は実装前に両ブラウザで確認し、トラック調整によって色が変化・消失しないようにする。色だけに頼らず、既存の日英文・強度ラベルも保持する。

- `meter`の意味・min/max/low/high/optimum/valueと0〜3の評価、15文字・72バイト等の判定を変更しない。判定処理を表示コンポーネントへ複製しない。
- まず既存meterの外観調整で対応する。ブラウザ差から補助的な描画が必要な場合も、読み上げ対象は1つにし、meterと表示値がずれないようにする。
- 共通`PasswordStrengthMeter`を通じて、新規登録、本人パスワード変更、メール再設定、弱いパスワードの変更要求、親によるメンバー再発行等の現存する全利用箇所へ適用する。個別画面に同じCSSを複製しない。
- Chromium／iPhone WebKitの日英・ライト／ダーク、値0〜3、狭幅、無効／処理中状態で可読性と既存の保存可否を確認する。iPhone Safari実機でもバーを確認する。

## 11. 承認後の実装・ローカル検証記録

### 11.1 R01の原因と修正

file input自身が発するcancelは親へバブリングする。現行dialogの`@cancel.prevent`は発生元を区別せず、画像選択のキャンセルもモーダル終了として扱っていた。[HTML Standardのinput共通API](https://html.spec.whatwg.org/multipage/input.html#common-input-element-apis)と[MDNのcancelイベント](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/cancel_event)のイベント契約にも一致する。

`@cancel.self.prevent`へ限定し、dialog自身の終了要求だけを従来のclose処理へ渡す最小修正とした。ファイル選択の待機フラグや固定タイマー、端末判定、復帰時の再オープンは不要で、追加していない。既存のfile change・画像変換・保存・メンテナンス／破棄時の終了を維持する。

既存画像E2Eに、実際のfile inputからbubbles=true／cancelable=falseのcancelを発生させる回帰を追加。選択前の本文・メモ・カテゴリ・日付・時刻保持、選択後の複数回キャンセルでのプレビューURL保持、保存API未送信、その後の保存と通常Escapeでの終了を確認した。OSのネイティブメニューそのものをWindowsから操作した結果ではなく、iPhone Safari／PWAの実機再現・合格はステージングで確認する。

### 11.2 表示調整・README

- 一覧メモは指定pathのnote-text-outline.svgへ置換。装飾アイコンをaria-hiddenにし、日英noteLabelを視覚非表示で付け、原文・改行・長文折返しを維持。参照のなくなったnoteTextを整理し、辞書数は日英487キーを維持した。
- 強度計はネイティブmeterと値・属性・判定を保持し、appearanceとトラックの枠・高さ・丸角・テーマ背景だけを調整。アクティブ値の色は上書きせず、各ブラウザの従来色を維持した。日英・ライト／ダークの0〜3と320px幅を検証し、Chromium／WebKit画像を確認した。
