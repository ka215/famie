## 保存・説明の対応

| 対象 | 実装・検証 | 公開文書との対応・管理方法 |
| --- | --- | --- |
| 認証Cookie `auth_token` | `useAuth.ts`はmaxAge 30日、Path `/`、SameSite Lax、production buildでSecure。JSからBearer認証へ利用しHttpOnlyではない。合成ログインでSecure・非HttpOnly・期限・Path・host限定を確認。Laxを含む書込み属性も確認 | Cookieポリシー1節の認証・30日と一致。ブラウザーでのCookie消去はアカウント削除ではなく、サーバートークンの失効確認とも区別する |
| サーバートークン | `AuthController`の登録・ログインで30日後をexpiresAtへ指定。logoutは現在のトークンを削除 | Cookie側の保存期限とサーバー側の有効期限を別に説明している。今回の実トークン生成・失効試験は実施しない |
| テーマ `famie-theme` | `theme.js`が初回表示で保存値またはOSの明暗設定を選びlocalStorageへ保存。TTLなし。匿名画面でも初期保存される | Cookieポリシー1節が初回自動保存を明記し、同意の操作とみなしていない。P06に従い保存前の許可UIを追加しない |
| 未ログイン言語 `famie.uiLocale.guest` | `useUiLocale.ts`で言語選択時にlocalStorageへ保存。TTLなし。匿名観測でも選択前はなし、en選択後にキーが増えることを確認 | Cookieポリシー1節の言語・自動期限なしと一致。ログイン利用者のDB上の言語設定とは別 |
| PWA Cache Storage | `nuxt.config.ts`のprecacheは静的HTML/JS/CSS/SVG等。API GETはNetworkOnly。配布SWを有効にしたChromium/WebKitで静的キャッシュが存在し、ローカルAPIへのGET後もAPIの保存0件・外部originの保存0件を確認 | Cookieポリシー1節の静的配信・ブラウザーや更新状況に依存と一致。API応答・投稿・画像のオフライン保存を保証する文言はない |
| メモリ・sessionStorage等 | 本体ソースのsessionStorage/IndexedDB書込みは確認されない。退会確認コードの引継ぎはNuxtのuseStateによるメモリ。合成ログアウト後のsessionStorageは空 | メモリの保持と永続保存を混同しない。未調査の依存実装やブラウザー内部保存まで不存在と断定しない |

Cookieポリシー2節はブラウザー設定での管理・消去、保存制限によるログインや設定保持への影響、端末データ消去とアカウント削除の違い、共有端末でのログアウト、独自の保存許可・拒否UIがないことを案内している。合成ログアウトでは認証Cookieが消え、テーマ・ゲスト言語だけが残ることを確認した。

現在のコードで外部広告・解析SDKは確認されない。匿名画面の観測範囲では通信先は同一originのみ。将来の追加処理まで含む不存在・法的免除の保証にはしない。新たなSDKや外部送信を追加する場合は棚卸しと運営判断を更新する。

## WebKitの計測上の制約

WindowsのPlaywright 1.63.0/WebKitでは、BrowserContext.cookies()のSameSiteがNoneとなった。Famieを起動せず、静的ページから直接設定したLax・Strictの比較用Cookieも同様にNoneとなったため、この結果だけでFamieの属性指定不良とは判断しない。

検証では値を記録せず、アプリがCookie setterへ渡す属性を観測し、認証Cookieの非空書込みすべてにSameSite=Lax・Secure・Path=/・Max-Age=2592000があることを確認する。Chromiumでは保存後のLaxも確認した。Windows WebKitのテスト結果にはmeasurement-limit注記を付け、実機Safariのクロスサイト制御まで検証済みとはしない。

[PlaywrightのCookie取得API仕様](https://playwright.dev/docs/api/class-browsercontext#browser-context-cookies)が示す属性情報と、今回の比較観測・アプリの書込み指定を分けて扱う。
