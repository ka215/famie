`frontend/nuxt.config.ts`は`ssr: false`で、build/generateはi18n生成後に`nuxt generate`を行う。単にVueからHTML文字列を参照するだけでは配信HTMLへ本文が直接入る保証がない。法務文書はビルド前に独立した静的HTMLを生成し、Nuxtの通常画面とは別に配布する案とする。ログイン・登録・設定から通常のリンクで到達させる。

JavaScript・API・DB・認証が利用できなくても本文を読めることを受入条件にする。静的HTMLはアプリの認証middlewareを通さず、Apacheの実ディレクトリとして配信する。未実装のNuxt法務ページと同じURLへ二重生成しない。配布成果物のmanifestに含め、部署外のCDN・実行時Markdown取得を追加しない。

## ソースと版

```text
frontend/content/legal/
  terms/<document-version>/ja.md
  terms/<document-version>/en.md
  privacy/<document-version>/ja.md
  privacy/<document-version>/en.md
  cookies/<document-version>/ja.md
  cookies/<document-version>/en.md
  manifest.json
```

文書版はアプリ版と独立し、公開後の本文は上書きしない。作業中原案と公開用ソースは分け、REVIEW注記を公開用へ移したままビルドしない。

メタデータは文書ID、文書版、各言語のタイトル・URL・本文SHA256、正文言語ja、公開日、施行日または施行予定、再確認を必要とする版を持つ。具体的な暦日が未確定な現在は`effectiveAt: null`と`effectiveOnRelease: "1.0.0"`を区別し、今日の日付や架空の将来日へ補完しない。未施行でも先行同意を取得する対象版を明示し、「施行中版がないから同意できない」実装にしない。

ハッシュはUTF-8・BOMなし・改行LFの原文バイト列を対象にし、末尾改行を含めた規則を固定する。公開後の改行差分も新しい版として扱う。日本語と英語は別のハッシュを持ち、操作時の表示言語に対応するハッシュを記録する。正文日本語への対応は同一文書版で追跡する。

## 生成・表示

- 既存のbuild/generateへ前処理を組み込み、devも同じ生成物を参照する。既存i18n処理は維持する。
- Markdown parserは既存の直接依存・lockfileで未確認。marked等の最小構成を選び、導入前に保守・ライセンス・監査を確認する。手製の正規表現だけでMarkdown parserを作らない。
- raw HTML・画像・iframe・script・イベント属性等を禁止し、リンクは許可するURL方式と内部参照のみを受け付ける。HTMLの許可要素・属性を限定して安全な生成を行う。marked単体を無害化処理とは扱わない。
- 日英ペア不足、不明文書、版重複、REVIEW残存、不正URL、版情報・ハッシュの不一致でビルド失敗。出力パスをソース名から自由生成せず、固定文書ID・版・localeの検証を行う。
- URLは`/legal/<document>/<version>/<locale>/`を不変の参照先とし、`/legal/<document>/`は日本語の最新版、`/legal/<document>/en/`は英語の最新版を表示する案。正文・施行予定・文書版・改定概要・言語リンク・ログイン等への戻りリンクを本文HTMLへ含める。
- 旧版は公開時の本文とメタデータを保持する。PWAで旧版が見える場合でも、その文書版を明示する。先行同意対象・再同意対象の最終判断は通信時のAPIと照合する。

## APIと履歴への接続

同一の生成マニフェストをバックエンド用成果物にも収録する。フロントとAPIを別々の手編集で更新しない。APIは対象文書・版・言語・ハッシュをサーバー側の許可一覧から確定し、クライアント指定のユーザー・日時・ハッシュを信用しない。版不一致時は409で再表示させる。

履歴は承認済みの内部ユーザーID、文書・版・本文ハッシュ、操作区分、サーバー日時、表示言語のみ。IP・User-Agent、未承認の代理人情報等を追加しない。退会・対象アカウント削除時の履歴削除を同時に設計する。代表者の同意を別メンバーの本人同意にしない。

重要改定時の制限対象は未確認の代表管理者本人のみ。文書閲覧・確認操作・問い合わせ・ログアウト・退会等を許可し、他メンバーを止めない。再同意対象版と表示上の最新版を分け、誤字修正だけで再同意を要求しない。
