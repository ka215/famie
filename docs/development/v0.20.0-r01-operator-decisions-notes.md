## 本文・挙動の確定前に残る事項

提供元の固有名・製品名を公開本文へ固定しない方針は、セキュリティに加え、将来のサービス拡張・提供元変更への柔軟性を確保する目的でも承認された（2026-11-08）。変更時は内部棚卸しと実態を更新し、処理内容に重要な変更があればP07・適用法令に従って説明・確認する。名称省略によって通知等の必要性まで一律に免除しない。

- 全世界を想定した提供方針に対応する地域別の利用条件、とくに子ども・保護者確認・権利請求・データ取扱いの条件。
- 日本法準拠、東京地方裁判所の第一審の専属的合意管轄、日本語正文は確定。適用される強行法規上の権利を制限しない条項とする。
- 追加開示は請求に応じて遅滞なく回答する方式で確定。公開する請求案内と回答手順を整備する。適用される地域別の追加要件は別途確認し、氏名・住所等をチャットへ提出するよう求めない。
- P02は一律の成人・続柄要件を採用しない方針に変更。地域別に法令上必要な確認等と、P03〜P07の同意・既存利用者・改定・保存分類・期限等は別途確定する。parentロールを法的保護者の確認にしない。
- 施行日はv1.0.0公開日を予定。v0.20.0から先行公開・同意取得する。具体的な暦日・公開日・公開用文書版は未確定。現在日付で自動補完しない。

生年月日収集や国別アクセス制限を、この記録だけを根拠に実装しない。全世界を想定する方針の下で必要な条件を整理し、未確定の条件や実装上の不足を運営者の判断へ戻す。

## 公式情報で確認した論点

メール任意・本名不要という利用形態を「完全匿名の保証」「個人情報を一切扱わない」とは表現しない。投稿・画像・他情報との照合により個人を識別できる場合がある。[個人情報保護委員会Q&A](https://www.ppc.go.jp/personalinfo/faq/APPI_QA/)参照。クローズドな共有と投稿の外部拡散可能性を両方説明する。

- [欧州委員会：GDPRの適用](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/application-gdpr_en)：EU域外の事業者でも、EU内の人へのサービス提供等が適用判断に関わる。「英語版がある」「海外も含む」だけで一律の適用/非適用を判定しない。
- [EDPB：同意を根拠とする処理・子ども](https://www.edpb.europa.eu/sme/be-compliant/process-personal-data-lawfully_en)：子どもにオンラインサービスを提供し同意に依拠する場面では、国ごとに13〜16歳の範囲で異なる条件を確認する。全処理・全世界へ同じ年齢を機械的に適用しない。
- [FTC：COPPAの対象](https://www.ftc.gov/legal-library/browse/rules/childrens-online-privacy-protection-rule-coppa)、[対応手順](https://www.ftc.gov/business-guidance/resources/childrens-online-privacy-protection-rule-six-step-compliance-plan-your-business)：対象サービスでは13歳未満の情報収集に関する告知・確認可能な保護者同意等を確認する。規約に保護者同意の一文を置くだけで対応済みとしない。
- [個人情報保護委員会：通則編3-8](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)：保有個人データに関する氏名/名称・住所等の本人の知り得る状態への対応を、公開用の屋号表記とは別に確認する。

これらは公開前に確認する論点の整理であり、全対象国の法令調査・適合性確認の完了を示さない。法令と実際の提供範囲・データ処理が対応するよう本文と実装を確定する。
