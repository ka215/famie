## ブラウザ保存

| 項目 | ソースで確認したこと | 今回の実測と残件 |
| --- | --- | --- |
| 認証Cookie `auth_token` | `frontend/app/composables/useAuth.ts`でmaxAge30日、path=/、SameSite=Lax、production buildではSecure。クライアントJSで読み、`useApi.ts`からBearerとしてAPIへ送る。DomainとHttpOnlyの指定なし | 未ログインではCookie0件。ログイン後の実属性・失効・ログアウト削除は今回未実測。値は収集しない |
| サーバー認証トークン | `AuthController`の登録・ログインでexpiresAtを30日後へ設定 | 今回は生成していない。Cookieの有効期限とサーバー側の失効を混同しない |
| テーマ `famie-theme` | `frontend/public/theme.js`でlocalStorageへ保存。保存値がなくてもOS設定等から初期テーマを選び保存する。明示TTLなし | 両画面で初期表示からキーが存在。利用者が選択した場合だけの保存とは記載しない |
| 言語 `famie.uiLocale.guest` | `useUiLocale.ts`と`shared/utils/locale.ts`。未ログインの言語選択をlocalStorageへ保存。明示TTLなし | 今回は言語選択せず、キーなし。ログイン利用者のui_localeはアカウントのDB項目なので別に説明する |
| sessionStorage | 確認した本体ソースに利用箇所なし | 両画面でキー0件。未確認画面・依存コードまで不存在を証明したとはしない |
| PWA | `nuxt.config.ts`で静的JS/CSS/HTML/SVG等をプリキャッシュ、旧cache整理、API GETはNetworkOnly | SWをblockした今回の実測対象外。公開文書の旧版・更新時の保持も実装後に確認する |

これらの技術上の事実だけで、Cookie等の「必須」分類や同意の不要を法的に確定しない。R04で対象地域・実態に応じて判断する。
