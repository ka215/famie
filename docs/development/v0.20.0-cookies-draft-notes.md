## 日本語原案

### 1. 対象

Famieでは、Cookieのほか、ブラウザーのlocalStorageやPWAのキャッシュを利用する処理があります。これらは同じ保存方法ではありません。運営者はMAGIC METHODS（個人事業主）、問い合わせ先はsupport@famie.coです。

### 2. 保存するもの

| 名称・方式 | 用途 | 期間・削除 |
| --- | --- | --- |
| `auth_token` / Cookie | ログイン認証用のトークン | コード上の有効期間は30日。サーバー側トークンにも30日の期限がある。ブラウザー設定から削除可能 |
| `famie-theme` / localStorage | 明暗の表示設定 | 初回表示でもOS設定等から自動保存。自動有効期限の設定なし。ブラウザーのサイトデータ削除で削除可能 |
| `famie.uiLocale.guest` / localStorage | 未ログイン時に選んだ言語 | 言語選択時に保存。自動有効期限の設定なし。ブラウザーのサイトデータ削除で削除可能 |
| PWA / キャッシュ | 静的な画面・スクリプト等の配信 | 構成上は旧キャッシュの整理を行う。端末・ブラウザーにも依存。APIのGETはNetworkOnly設定 |

ログイン中の表示言語はアカウント側にも保存されるため、端末側の消去とは区別します。[REVIEW-P06：各保存の必須性・利用者が求めた設定との関係、同意の要否を地域別に確定。テーマの初回自動保存を利用者の明示選択と扱わない]

### 3. 選択と制御

ブラウザーの設定でCookieやサイトデータの保存・削除を管理できます。保存を制限するとログインや設定の保持が機能しない場合があります。端末上のデータ削除はアカウント・投稿の削除ではありません。共有端末ではログアウトも行ってください。

[REVIEW-P06/R04：運営判断により本版では保存制御UI等を実装しない。ブラウザー設定による制御を説明し、未実装の選択UIを案内しない。地域別に事前同意等が必要となる場合の対応は別途判断し、すべて同意不要とは断定しない]

### 4. 解析等と調査範囲

現時点の調査では外部の解析・広告SDKの導入は確認していません。匿名のログイン・登録ページの限定観測では外部宛通信やCookieを観測しませんでした。ただしログイン後の全機能・商用環境の網羅的な測定ではなく、PWAの実動作もこの観測では確認していません。[REVIEW：公開候補での最終確認と保存一覧の確定。調査注記を公開本文向けに書き換える]

## English draft

### 1. Scope

Famie has processes using cookies, browser localStorage and PWA caches. These are different storage mechanisms. The Operator is MAGIC METHODS (a sole proprietorship). Contact: support@famie.co.

### 2. Storage used

| Name and mechanism | Purpose | Duration and deletion |
| --- | --- | --- |
| `auth_token` / cookie | Authentication token for sign-in | Code specifies 30 days; the server token also expires after 30 days. Removable through browser settings |
| `famie-theme` / localStorage | Light/dark appearance | Automatically saved on initial display based on system settings or defaults. No automatic expiry configured. Removable through site-data settings |
| `famie.uiLocale.guest` / localStorage | Language selected while signed out | Saved when a language is selected. No automatic expiry configured. Removable through site-data settings |
| PWA / cache | Delivery of static pages, scripts and similar resources | Configuration cleans outdated caches. Duration also depends on the device and browser. API GET requests use NetworkOnly |

Signed-in language preferences are also stored with the account; clearing device storage is a separate action. [REVIEW-P06: classify necessity, relationship to requested preferences and regional consent requirements. Automatic initial theme storage is not an explicit user selection.]

### 3. Choices and controls

Browser settings let you manage cookies and site data. Restricting storage may prevent sign-in or preservation of preferences. Clearing device storage does not delete an account or its content. Also sign out on shared devices.

[REVIEW-P06/R04: the Operator has decided not to implement storage-control UI in this release. Describe browser controls, without referring to unimplemented preference controls. Assess separately any regional requirements for prior consent; do not assert that all storage is exempt.]

### 4. Analytics and observation limits

The current investigation has not identified an external analytics or advertising SDK. Limited observations of anonymous sign-in and registration pages found no external requests or cookies. These observations do not cover every signed-in feature or production, and did not verify runtime PWA behavior.
