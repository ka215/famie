# 商用IP制限を環境設定で解除する

## 背景

[v0.9.0詳細要件](../../issues/v0.9.0.md)に従い、商用を自宅等の許可IP以外から利用できるようにする。ステージングのIP制限は維持する。新規登録・複数家族対応はまだ実装しない。

## 決定

- Laravelに`IP_RESTRICTION_ENABLED`を追加し、未指定時はtrue、明示的なfalseのみ制限解除とする。有効時の空許可リストは従来どおり全拒否。
- `APP_ENV`は両環境でproductionのため切り替えの判断に使わない。
- 商用のApache側制限は別工程で解除し、ステージングの二層の制限は維持する。
- 成果物は両環境で共通とし、保持対象の`.env`・`.htaccess`で環境差分を管理する。
- 配置検査はステージングの解除設定を拒否する。商用は解除前・切り戻し後の制限有効状態も認め、解除完了は別回線からのHTTP・認証確認で判定する。

## 理由

許可リストの空欄を解除扱いに変更すると、既存環境で誤って公開される。明示的な設定とすることで既存の全拒否動作を保持できる。また、配置時に`.htaccess`を丸ごと上書きするとメンテナンス等の設定を失うため、IP制限部分だけを調整する。

## 影響

商用の画面・静的資産・ログインAPIは接続元IPを問わず取得できる。活動データは既存の認証・権限で保護する。コード更新だけでは公開範囲は変わらず、商用配置時に設定反映と確認が必要。現時点では商用・ステージングの設定は未変更。
