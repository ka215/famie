# 現行文書と初期リリース仕様の適用範囲

## 背景

v0.16.1の文書棚卸しで、v0.16.0の移管後も基本設計に旧商用ドメイン、API説明に旧対象版・ルート数、READMEに提供済み機能を未提供とする記述が残っていた。初期リリースの要件・設計には、その後の家族モデル・画像・リワード等と異なる記述もある。

## 決定

- 現行の商用URLは `https://famie.co`、公開先は `~/public_html/famie.co`。ステージングは従来どおり。旧商用URLは転送・復旧対象として保持する。
- 正式要件・基本設計の初期リリース部分を全履歴の正本とはせず、冒頭に後続版で確定した仕様の適用表を置く。適用表に示した版別仕様・API契約を該当項目で優先する。未実装の多言語化素案は現行仕様へ繰り上げない。
- README、索引、現行手順・設定例、API契約の対象版を現状へ整合する。
- `docs/reference/`、過去版の仕様・公開記録・意思決定は当時の証跡として保持する。旧ドメイン文字列を一括置換しない。旧URLの転送・復旧、メール送信元の切替前設定、ステージングのFQDNは必要な記述として区別する。
- v0.16.1のメール移管は環境設定と実配送確認を伴う別作業。未確認の新送信元を、すでに稼働中と記載しない。

## 理由

旧URLの証跡や切り戻し条件を消さず、現在の運用と機能を参照できるようにするため。文書更新だけで製品仕様・データモデル・権限を変更しない。

## 影響

現行文書は適用表から対象の版別仕様や実API契約へ進める。新たな機能変更では該当する版別仕様と適用表を更新する。初期仕様の表を単独で現行機能・権限の受入基準には使わない。
