### 実装・検証状況

`feature/v0.3.0` にて以下を実装。公開済み。下表はリリース前時点の検証記録であり、個別の実機確認結果を追加で推定しない。

| 課題 | 実装とローカル検証 | 残る確認 |
|---|---|---|
| 1 | 日付・時刻欄の幅を制約。Chromium / iPhone 相当の WebKit で非重複と入力・保存を確認 | iPhone 実機の Safari / PWA での確認 |
| 13 | 専用の一時 SQLite DB と実 API を使う Playwright を導入。ログイン・登録・再表示・ログアウトを検証 | 本番 PostgreSQL 固有の動作は対象外 |
| 4 | 6箇所のパスワード欄を共通化。親・子アカウントの表示切り替えと値の保持・欄ごとの独立性を検証 | リリース時の画面確認 |
| 12 | Windows の準備スクリプト、CoreServer の共通配置スクリプトと復旧手順を追加。準備の一連実行、配置スクリプトの構文・入力拒否4件を確認 | CoreServer での配置・復旧検証、jq などの前提確認 |

Lint、型チェック、E2E 6件、静的生成は成功。本流の実装コミットには生成物を含めず、リリース準備時に再生成して別途コミットする。本番配置は完了。ユーザーよりメンテナンス解除と正常リリースを確認済み。PHP CLI・Composer・公開権限の修正を適用し、修正版 deploy-cli.sh もサーバーへ反映済み。これらの正式な統合は v0.4.0 で扱う。
