# 画面推移図 & APIエンドポイント設計書

## 1. 画面推移図 (Nuxt 4 フロントエンド)

```
[ ログイン画面 (/login) ]
       │
       ▼ (認証成功)

│  メインレイアウト (ボトムナビゲーション / ヘッダー)       │
│                                                         │
│  [ タイムライン（ログ一覧）画面 (/) ] ◀━ (デフォルト)   │
│       │                                                 │
│       ├──▶ [ ログ新規登録画面 (/logs/create) ]           │
│       │         │                                       │

│       │                                                 │
│       ├──▶ [ ログ詳細・編集画面 (/logs/:id) ]           │
│       │         │ ※ 親: 全員分可 / 子: 自分のログのみ │
│       │         └─▶ (更新/削除後) ──▶ タイムラインへ戻る  │
│       │                                                 │
│       └──▶ [ 期間指定・フィルタモーダル/ダイアログ ]    │
│                                                         │
│  [ 設定 / ユーザー管理画面 (/settings) ]                │
│       │                                                 │

```

### 画面一覧・アクセス権限

| 画面名 | パス | 説明 | アクセス権限 |
| --- | --- | --- | --- |
| **ログイン** | `/login` | アカウント名/メアドとPWでログイン | 全体 |
| **タイムライン** | `/` | 家族全員のログ一覧表示・期間フィルタ | ログイン全ユーザー |
| **ログ新規登録** | `/logs/create` | 新しいアクティビティログを作成 | ログイン全ユーザー |
| **ログ詳細・編集** | `/logs/:id` | ログの詳細確認および編集・削除 | **親**: 全件編集可<br>

<br>**子**: 自ログのみ編集可 |
| **設定・ユーザー管理** | `/settings` | ユーザー追加（親のみ）、パスワード変更 | ログイン全ユーザー（一部機能制限あり） |

## 2. APIエンドポイント一覧 (Laravel 8.4~ バックエンド)

ベースURL: `/api/v1`
認証方式: Laravel Sanctum (CookieまたはBearer Token)

### 2.1 認証・ユーザー情報関連 (`/auth`, `/users`)

| メソッド | エンドポイント | 内容 | ロール制限 | 備考 |
| --- | --- | --- | --- | --- |
| `POST` | `/auth/login` | ログイン処理 | 全体 | `username` または `email` で認証 |
| `POST` | `/auth/logout` | ログアウト処理 | ログイン済 | トークン破棄 / セッション削除 |
| `GET` | `/auth/me` | ログイン中ユーザー情報の取得 | ログイン済 | ロールや表示名の取得 |
| `GET` | `/users` | ユーザー一覧の取得 | ログイン済 | ログ投稿者のフィルタリング用選択肢などに使用 |
| `POST` | `/users` | 新規ユーザー登録 | **親のみ** | 子供などのアカウント追加 |
| `PUT` | `/users/{id}/password` | パスワード変更 | 自身 / 親 | 親は子のPWリセット可 |

### 2.2 カテゴリ関連 (`/categories`)

| メソッド | エンドポイント | 内容 | ロール制限 | 備考 |
| --- | --- | --- | --- | --- |
| `GET` | `/categories` | カテゴリ一覧取得 | ログイン済 | 選択肢表示用 |
| `POST` | `/categories` | カテゴリ追加 | **親のみ** | 必要に応じて追加可能 |

### 2.3 アクティビティログ関連 (`/logs`)

| メソッド | エンドポイント | 内容 | ロール制限 | 備考 |
| --- | --- | --- | --- | --- |
| `GET` | `/logs` | ログ一覧取得 | ログイン済 | クエリパラメータで期間・ユーザー指定可 |
| `POST` | `/logs` | ログ新規作成 | ログイン済 | 自身の `user_id` で作成 |
| `GET` | `/logs/{id}` | ログ詳細取得 | ログイン済 |  |
| `PUT` | `/logs/{id}` | ログ更新 | **親 / 作成者** | 子アカウントは他人のログ更新不可（403 Forbidden） |
| `DELETE` | `/logs/{id}` | ログ削除 | **親 / 作成者** | 子アカウントは他人のログ削除不可（403 Forbidden） |

#### ログ一覧取得時のクエリパラメータ例 (`GET /api/v1/logs`)

* `from`: 開始日 (例: `2026-09-01`)
* `to`: 終了日 (例: `2026-09-21`)
* `user_id`: ユーザーID絞り込み (オプション)
* `category_id`: カテゴリ絞り込み (オプション)

## 3. Laravelでのアクセス制御・ポリシー実装イメージ

### 3.1 IPアクセス制限 (Middleware)

`app/Http/Middleware/RestrictIpAddress.php` 等で実装し、`bootstrap/app.php`（Laravel 11+ / 12）または `Kernel.php` に登録します。

```php
// 例: 特定のIP以外を遮断
$allowedIps = explode(',', env('ALLOWED_IPS', ''));
if (!in_array($request->ip(), $allowedIps)) {
    abort(403, 'Access denied from your IP address.');
}

```

### 3.2 ログ更新・削除権限ポリシー (ActivityLogPolicy)

LaravelのPolicy機能を使用して、親アカウントか本人であるかを判別します。

```php
public function update(User $user, ActivityLog $log): bool
{
    // 親（管理者）なら常にOK
    if ($user->role === 'parent') {
        return true;
    }
    // 子供（一般）なら自分のログのみOK
    return $user->id === $log->user_id;
}

```
